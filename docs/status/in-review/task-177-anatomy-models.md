decision: D-pending (Task 177) Both 4.0 trees are used. The PART-OF tree has the skin, nervous system, heart chambers, aorta, venae cavae and the organs, but no skeletal muscles and no artery or vein concept, and mixes bones, muscles and vessels in its limb concepts; the IS-A tree sorts by kind. So the organs and the brain and spinal cord use PART-OF, and muscle (`muscle organ`), arteries and veins, bones (`bone organ`), peripheral nerves (`segment of neural tree organ`) and skin use IS-A. Each element mesh is drawn once across the whole body: the first system in the file keeps it. Reason: whole-body layers need non-overlapping models, and names stay exactly the release's own.
