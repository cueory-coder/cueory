# Brand reference archive

These seven founder-provided files are preserved as **historical source references** from `main`. Their original bytes must remain unchanged for provenance.

For the current Cueory website and product, follow the approved rules in [CLAUDE.md](../../CLAUDE.md), [docs/BRAND.md](../BRAND.md), and [brand-source/v1.0/Cueory_Brand_Guide.md](../../brand-source/v1.0/Cueory_Brand_Guide.md). Those current rules take priority when older reference documents disagree.

**Known conflict:** `Cueory_Branding_Spec.md` recommends *Inter* for website body text, navigation, and buttons. The current `CLAUDE.md` requires **Lato** for body and interface text and **Bodoni Moda** for marketing headings. Do not replace the approved typography with Inter based on this historical reference.

Do not regenerate, redraw, recolor, compress, or replace the original reference artwork as part of its archival preservation. Production assets remain governed by the current reviewed brand guide.
