# Cueory

Production website for Cueory, built from the approved design decisions in `cueory-design`.

## Stack

- Astro
- React islands for interactive games
- Shared CSS design tokens in `src/styles/tokens.css`

## Development

```sh
npm install
npm run dev
npm run check
npm run build
```

Brand artwork must come from the supplied originals under `public/brand/v1/`; never recreate, trace, or recolor it.
